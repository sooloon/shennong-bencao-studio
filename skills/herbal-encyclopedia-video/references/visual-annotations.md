# 标注、分组与阅读节奏

用户2026-11-13对葛根V4的明确修订：地图地名直接在图上标注；其他画面也应按内容采用合适的表现，不能把所有文字都框起来。时长由内容完整性和合理性决定，2–3分钟均可，1:50、3:10也可。

## 选择与对象相符的表现

| 内容关系 | 首选表现 | 需要避免 |
|---|---|---|
| 地域位置 | 地名在对应省域附近，必要时红点加短引线，文字克制地避让 | 图外一排红框，观众还要来回找对应关系 |
| 植物部位 | 贴近叶/藤/根的标注和短连线 | 把编号放在图外，无法知道指向哪个对象 |
| 来源、术语比较 | 并列对齐、字号层级、留白、必要的等号/不等号 | 每一列再套重复边框 |
| 工序顺序 | 编号、方向、依次出现的动词 | 所有步骤都做相同弹框 |
| 数值比例 | 数值、单位、参照物与变化过程；百格可作为量化单元 | 把边框当成数字的装饰；比例无口径 |
| 真实容器或表格 | 按实际对象和阅读需要保留边界 | 为了“去框”而破坏表格或比例单元的含义 |

保持用户已认可的精细黑白植物雕版插画和少量红色，修改视频里的标注层与排版，不用更简陋的图形替换主体。

地图底图完整性规则仍有效：地名、数字、引线不遮挡台湾、海南、南海诸岛附图及重要岛屿/边界，不通过AI重画地图。必要时调整注记位置；不能用加大文字遮住本来需要保留的内容。

## 时长与动效

先列完整的知识链，再按字数、图形复杂度、逐步揭示所需时间安排各镜头。典籍原文、地图、数字换算比单一名称过渡多留时间。适当留读图时间，不把停顿一律当作坏事，也不靠持续晃动掩盖信息重复。

动效表达关系：先到对象再出名称；工序沿顺序展开；比例先建立整体再解释其中一部分。不要给所有文字套同一种弹框。音乐为内容服务，允许在不破坏听感的前提下对同一曲目做乐句衔接和交叉淡化；按最终音轨安排镜头节奏。
