# 工具调用与替换

| 步骤 | 这次实际使用 | 跨模型/agent 替代 |
|---|---|---|
| 典籍及事实核查 | 网络搜索、原始页面/规范PDF | 任意可读取原始机构资料的搜索或浏览工具；记录同样的 sources 字段 |
| 植物插画、四格细节、封面 | image_gen 图像生成/编辑 | 其他图像模型可按 prompts 输出同路径PNG；先看参考图、核对解剖和中文，再接入渲染 |
| 正文与图形动效 | Python Pillow + NumPy；重音分析曾使用 SciPy | 已封装成本地 CLI；模型只编辑 JSON/必要布局代码 |
| 配乐、导出、视频抽帧 | FFmpeg / ffprobe | 本地同名可执行程序 |
| 保存到 GitHub | GitHub 连接工具、GitHub 网页建私有仓库、本地 Git 批量上传 | 标准 Git 即可；凭证由环境正常认证，绝不写入项目 |

渲染既有素材无需任何云模型 API。ChatCut、HyperFrames、TTS 没有参与最终V7制作，不是隐藏依赖。`tools-manifest.json` 提供机器可读的抽象工具映射。图像生成提示词中标注“重建”的部分是根据最终画面整理的可复用提示词，不冒充完整历史调用逐字日志。

不要为了复用安装未知来源的软件或将钥匙写入配置。新图像生成是否付费、用哪家模型，由实际环境和用户选择决定，不预设消费或后台任务。
