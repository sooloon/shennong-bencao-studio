# 制作下一期

1. 从用户指定的部类、品级、顺序号查底本，不从发布期次推药名。核对前后条目，并在 `sources` 记链接、版本和支持哪些事实。
2. 写一条连续的问题线：2秒内可理解的钩子，名称与来路，典籍短句和白话解释，部位/形态，地域，传统用途与关键区别。信息服务于这条线，不要求每味药都有同样的段落。
3. 使用 `new` 建草稿。把封面、原植物、药用部位和细节图放在该期 `assets/`；不能改用葛根旧图。图片生成提示词见 `prompts/`，工具可换。
4. 参考葛根 JSON 选布局，填 `data`。地图点和引线是当前底图的720×1280画布坐标，不是经纬度；换底图必须重新核对，不能照搬旧坐标。
5. 每个事实场景记录 `source_ids`。数字有单位、年份/版本、口径与边界；地域区分产地举例、分布与种植实例。没有研究数字时不编造疗效比例。
6. 先按阅读速度给 `hold`。改变镜头数或时长后清空 `locked_cuts`，让时间轴按新 hold 生成；葛根基版锁定的音乐重音切点只适用于该版本。
7. 资料和素材准备好后设 `status=ready`，运行 doctor、storyboard、地图或关键数字短片段，再导出全片。用最终编码文件抽帧，不只看脚本静态预览。

`render` 会基于已配置的同曲乐句做交叉淡化，支持内容时长变化。若更换音源，核对 `music.edit` 的切片时间是否仍在音源内。默认不配音。

基版提供已用布局与 draft 模板，不提供365味药完整事实库，不声称任何新药材只改药名即可自动完成。需要新图形时增加合理布局并保留项目风格。
